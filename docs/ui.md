# Оформление интерфейса

Bootstrap 5.3 без сборки, поверх него свой слой стилей. Все библиотеки лежат локально, внешних запросов нет (приложение работает без интернета).

## Где что лежит
- `src/main/resources/static/vendor/` - Bootstrap 5.3.3, Bootstrap Icons 1.11.3 и Chart.js 4.4.3 (все MIT), без source map.
- `static/fonts/` - шрифт Inter (латиница и кириллица, лицензия OFL в `LICENSE-Inter.txt`).
- `static/css/app.css` - токены (цвета, радиусы, тени), темы, каркас (сайдбар, верхняя панель), переопределения Bootstrap.
- `static/css/components.css` - компоненты: мягкие бейджи, аватары, панель списка, карточка профиля, зона загрузки фото, показатели главной.
- `static/js/charts.js` - рисует графики Chart.js по описанию в атрибуте `data-chart` (подключается только на страницах с графиками).
- `static/js/app.js` - переключатель темы, всплывающие уведомления, подтверждение действий, поиск по таблице, предпросмотр фото.
- `static/img/logo-128.png` - логотип 128x128 (в боковом меню показан целиком по центру, в верхней панели на телефоне 40x40), `favicon.ico` - значок вкладки. Остальные файлы в `static/img` (`logo.png`, `favicon-16x16.png`, `favicon-32x32.png`) сейчас не используются.
- `templates/layout.html` - общий макет, `templates/fragments/ui.html` и `photo.html` - общие фрагменты.

## Темы
Светлая и темная через `data-bs-theme` на `<html>`. Выбор хранится в `localStorage` (ключ `theme`), по умолчанию как в системе; маленький скрипт в `<head>` ставит тему до отрисовки. Цвета только через переменные (`--app-*`, `--bs-*`), не через жестко заданные значения. Палитра серий графиков заранее: `--chart-1` ... `--chart-6` (Okabe-Ito, различима при дальтонизме, для темной темы светлее).

Акцент `#2563eb` (светлая) и `#60a5fa` (темная), графитовый текст и сайдбар. Проверено вручную по расчету контраста: основной и вторичный текст, ссылки, кнопки, сайдбар не ниже 4.5:1.

## Как добавить страницу
1. Шаблон с `layout:decorate="~{layout}"` и содержимым в `layout:fragment="content"`.
2. Заголовок страницы: `div.page-header` с `h1.h3` и подзаголовком `text-secondary`.
3. Список: `div.card` с `div.card-toolbar` (поиск через `data-table-filter="#таблица"` и `data-table-count="#счетчик"`), таблица `table table-hover align-middle`, строки с атрибутом `data-row`, строка пустого результата `data-filter-empty hidden`. Пустой список: `<th:block th:if="${#lists.isEmpty(x)}"><tr th:replace="~{fragments/ui :: emptyRow(колонок, 'bi-иконка', 'Текст')}"></tr></th:block>` (именно через `th:block`, иначе `th:replace` сработает раньше `th:if`).
4. Статусы и метки только фрагментами: `fragments/ui :: athleteStatus(...)`, `competitionLevel(...)`, `competitionStatus(...)`, `rank(...)`. Новый статус добавлять туда, а не в шаблон страницы.
5. Фото человека: `fragments/photo :: thumbnail(person)` в списках, `view(person)` на карточке, `input(person)` в форме.
6. Удаление и опасные действия: кнопка `type="submit"` с `data-confirm="Текст вопроса"` внутри `form`, модальное окно подтверждения общее в `layout.html`.
7. Сообщения пользователю: флеш-атрибуты `success` и `error` показываются всплывающими уведомлениями.
8. Формы: секции в `card`, заголовок секции `div.section-title`, обязательное поле помечать `<span class="required">*</span>`, панель кнопок `div.form-actions`. Поля дат `type="date"` заполнять значением в формате `yyyy-MM-dd`.
9. Числа дистанций и очков в таблицах: класс `num` (выравнивание вправо, цифры одной ширины), главное значение `num-strong`.
10. Активный пункт меню определяется по адресу страницы (`currentPath` из `NavigationAdvice`): новый раздел добавить в `layout.html` и использовать общий префикс адреса.

## Графики
1. Контроллер собирает описание графика в JSON (`ObjectMapper`): `type` (`bar`, `line`), `labels`, `datasets` (`label`, `data`), `yLabel`; пример в `AgeRecordController.buildChart`.
2. В шаблоне: `<div class="chart-box"><canvas data-chart th:attr="data-chart=${chart}" role="img" aria-label="Что на графике"></canvas></div>`.
3. Скрипты Chart.js и `charts.js` подключаются на странице блоком `<th:block layout:fragment="scripts">...</th:block>` (в `layout.html` для него есть место после `app.js`).
4. Цвета серий и текста берутся из CSS-переменных `--chart-1..6`, `--bs-secondary-color`, `--app-border`; при смене темы `app.js` шлет событие `themechange`, `charts.js` перерисовывает все графики.
5. Фильтры страницы (трамплин, пол) сделаны ссылками-таблетками `nav nav-pills` с параметрами адреса: страница каждый раз строится на сервере, без скрытых графиков.
